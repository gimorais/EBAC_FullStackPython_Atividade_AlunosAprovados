# Exercício ES6 – Array e Filter

Este projeto foi desenvolvido como exercício de JavaScript ES6.

## Objetivo
Criar um array de objetos representando alunos, contendo nome e nota, e aplicar um filtro para retornar apenas os alunos aprovados.

## Descrição
Foi criado um array de alunos e utilizada a função `filter()` para retornar apenas aqueles cuja nota é maior ou igual a 6.
